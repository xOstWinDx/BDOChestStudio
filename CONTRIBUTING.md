# Участие в разработке

Спасибо за интерес к BDO Chest Studio. Обсуждения ошибок и предложений —
в [Issues](https://github.com/xOstWinDx/BDOChestStudio/issues).

1. Создайте отдельную ветку для изменения.
2. Настройте окружение по [руководству](docs/DEVELOPMENT.md).
3. Внесите изменение, сохраняя разделение ядра и Qt-интерфейса.
4. Запустите Ruff, тесты и GUI smoke; для изменений интерфейса приложите скриншот.
5. Опишите в PR проблему, новое поведение и выполненную проверку.

Новые строки добавляйте в RU и EN. Для таблиц дропа указывайте источник и дату
проверки. Не обновляйте регрессионные эталоны только ради прохождения теста.
Для новых изображений укажите происхождение и условия использования в `docs/ASSETS.md`.

В репозиторий не должны попадать виртуальные окружения, exe, базы личной истории,
секреты, локальные настройки редактора или временные снимки тестов.
Вклад в собственный код проекта предоставляется на условиях MIT; сторонние материалы
сохраняют собственные лицензии и авторство.
