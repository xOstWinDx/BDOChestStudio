# История изменений

## 0.2.0 — 2026-09-26

Первое оформление настольного приложения как самостоятельного репозитория.

- Пакетная структура `src`, метаданные, запуск модулем и GUI-командой.
- 18 сундуков, 42 конечных предмета; каталог на конкретных Python-классах.
- Корзина, рекурсивная очередь, рулетка и карточки множественных наград.
- Рамки редкости, звуки, четыре темы и русский/английский интерфейс.
- Отчёт, локальная история SQLite и CSV-экспорт.
- Исправлен размер карточек обычной рулетки.
- README со скриншотами, документация, MIT и уведомления о сторонних материалах.
- Проверки GitHub Actions и ручная Windows-сборка.
- TUI-прототипы заменены независимыми эталонами в тестах.

Статус версии — alpha. Таблицы дропа требуют отдельной сверки с актуальной игрой.
